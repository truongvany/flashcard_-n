# Memora

A static React flashcard app with lightweight AI-inspired UI.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Deploy (Vercel / Render)

### Vercel
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

### Render
- Build command: `npm install && npm run build`
- Start command: `npm run start`

This project is static front-end friendly and does not require a database or backend service.
